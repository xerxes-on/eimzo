# Changelog

## 0.1.0

- Headless Linux PKCS#7 signing through the official E-IMZO 6.4.7 provider, with attached/detached output and verification before return.
- Encrypted certificate vault, separate password configuration, bounded subprocess execution and sanitized failures.
- Optional OpenSSL backend and loopback desktop E-IMZO client.
- Pinned runtime installer, Linux Docker integration test, PHP 8.2+ test matrix and MIT license for original code.

Initial API; vendor runtimes retain their own terms. This package does not certify relying-party acceptance, trust chains or revocation status.
